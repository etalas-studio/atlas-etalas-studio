Static landing page for Atlas by etalas studio.

- Netlify admin: https://app.netlify.com/projects/atlas-etalas-studio

## Source

- Main file: `index.html`
- Netlify headers: `_headers`
- Netlify site ID: `fb3d3130-7e51-4453-8af2-87fefbed7ebd`

## Update Flow

1. Replace `index.html` with the latest approved landing page HTML.
2. Keep `_headers` so Netlify serves the page as `text/html`.
3. Deploy to Netlify.
4. Commit and push the same update to GitHub.
